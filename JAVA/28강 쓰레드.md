## 자바 멀티스레드(Multithread) 프로그래밍 기초

### 1. 주요 용어 사전 (먼저 읽어보세요)

- **프로세스(Process):** 우리가 실행하는 프로그램 하나하나(예: 크롬 브라우저, 카카오톡 앱)를 말합니다.
- **스레드(Thread):** 프로세스 안에서 일을 처리하는 '작업 단위'입니다. 한 프로세스 안에는 여러 스레드가 있을 수 있습니다.
- **동기화(Synchronization):** 여러 스레드가 한 자원에 동시에 접근할 때, 순서를 정해 **충돌을 막는 작업**입니다.
- **원자성(Atomicity):** 작업이 더 이상 쪼갤 수 없는 '한 덩어리'로 완벽하게 처리되는 성질을 의미합니다.

### 2. 스레드의 핵심 개념

- **왜 스레드를 쓰는가?**
    - 하나의 프로그램에서 동시에 여러 가지 일을 하기 위해서입니다. (예: 음악을 들으면서 웹 서핑을 하기)
- **스레드 생성 방식:**
    - **방법 A:** `Thread` 클래스를 상속받기 (가장 기본적인 방법)
    - **방법 B:** `Runnable` 인터페이스 구현하기 (더 유연하여 실무에서 권장됨)
 
### 3. 스레드의 생명주기 (스레드가 태어나서 죽기까지)

- **New:** 스레드 객체가 만들어진 상태.
- **Runnable:** `start()` 명령을 받아 실행될 준비를 마친 상태.
- **Running:** 실제 CPU를 사용하여 `run()` 메서드 안의 코드를 실행 중인 상태.
- **Blocked/Waiting:** `sleep()` 등으로 인해 잠시 멈춰 대기하는 상태.
- **Terminated:** 모든 일을 마치고 종료된 상태.

### 4. 실무 핵심: 공유 자원과 동기화

- **Race Condition (경쟁 상태):** 여러 스레드가 "내가 먼저 쓸 거야!"라며 하나의 변수를 동시에 수정하려 할 때 발생하는 데이터 꼬임 현상입니다.
- **해결법:** `synchronized`라는 열쇠를 사용하여, 한 번에 한 스레드만 접근할 수 있도록 제한합니다.

## [강의 확인 문제]

- **Q1. 프로세스와 스레드의 차이점에 대한 설명으로 옳은 것은?**
    - A. 프로세스는 스레드보다 작은 작업 단위이다.
    - B. 하나의 프로세스에는 반드시 하나의 스레드만 존재해야 한다.
    - C. 프로세스는 프로그램 실행 단위이고, 스레드는 그 안에서 작업하는 최소 단위이다.
    - D. 스레드는 독립적인 메모리 공간을 가지지만 프로세스는 메모리를 공유한다.
    - **정답: C**
    - **설명:** 프로세스는 프로그램의 실행 단위이며, 스레드는 그 프로세스 내부에서 메모리를 공유하며 동작하는 세부 작업 단위입니다.
- **Q2. 'Race Condition(경쟁 상태)'이란 무엇인가요?**
    - A. 여러 스레드가 서로 끝나기를 기다리느라 프로그램이 멈추는 현상
    - B. 여러 스레드가 하나의 데이터를 동시에 수정하려고 할 때 값이 꼬이는 현상
    - C. 스레드가 너무 많이 생성되어 메모리가 부족해지는 현상
    - D. CPU가 스레드를 처리하는 속도가 너무 빨라 발생하는 오류
    - **정답: B**
    - **설명:** 여러 스레드가 동시에 공유 자원을 변경할 때, 처리 순서에 따라 결과값이 달라지는 데이터 불일치 문제를 말합니다.

- **Q3. 스레드를 실행하기 위해 반드시 호출해야 하는 메서드는?**
    - A. `run()`
    - B. `start()`
    - C. `execute()`
    - D. `sleep()`
    - **정답: B**
    - **설명:** `run()`은 단순한 메서드일 뿐입니다. `start()`를 호출해야 JVM이 새로운 실행 흐름(스레드)을 만듭니다.
- **Q4. 다음 중 '원자성(Atomicity)'을 보장하기 위한 도구로 적절하지 않은 것은?**
    - A. `synchronized` 블록
    - B. `AtomicInteger` 클래스
    - C. `Thread.sleep()`
    - D. `ReentrantLock` (참고: 상호 배제를 위한 락 도구)
    - **정답: C**
    - **설명:** `sleep()`은 단순히 스레드를 잠시 멈추는 기능일 뿐, 데이터의 원자성(데이터 처리가 쪼개지지 않음)을 보장해주지는 않습니다
